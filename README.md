# Snack Stack

[![ci-nextjs-application-template](https://github.com/snack-stack-uhm/snack-stack/actions/workflows/ci.yml/badge.svg)](https://github.com/snack-stack-uhm/snack-stack/actions/workflows/ci.yml)

Snack Stack is a web application designed to help users manage their pantry, shopping lists, and recipes efficiently.

## Features

- Pantry management
- Shopping list creation
- Recipe suggestions

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`

## Testing

- Run tests using Playwright: `npx playwright test`
